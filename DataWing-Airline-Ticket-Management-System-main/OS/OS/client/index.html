Flight Scheduling Module

Round Robin distributes runway time; Priority handles emergency departures

Round RobinPrioritySJFSRTFFCFS
RR
Round Robin — Runway Allocation
Each flight gets equal runway time slot. No single flight monopolizes during peak hours.
PRI
Priority — Emergency Departures
Emergency (P1) and VIP (P2) flights depart before domestic scheduled (P3).
SJF
SJF — Short Routes First
Short domestic flights (90min) get runway before long-haul when possible.
SRTF
SRTF — Dynamic Reallocation
Faster-to-depart flight preempts current one if it has shorter remaining prep time.

Flight Delay & Emergency Management

Priority Preemptive handles emergencies instantly; SRTF resolves delays efficiently

Priority PreSRTF Round RobinPriority NP
🚨 Emergency Management System Active — All algorithms on standby
PRE
Priority Preemptive — Emergencies
Emergency flight immediately preempts any running operation. Medical, security, weather handled instantly.
SRTF
SRTF — Delay Resolution
Flight with shortest remaining delay resolved first. Minimises total delay across fleet.
RR
Round Robin — Gate Reallocation
Delayed flights share available gate slots equally. Each flight gets fair chance.
PRI
Priority NP — Triage
Medical (P1) › Technical (P2) › Weather (P3) › Crew (P4). Non-preemptive once started.
